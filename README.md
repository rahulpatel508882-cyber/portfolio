# portfolio

A personal portfolio website for showcasing projects, experience, and contact details with a modern frontend and email-capable backend.

## Tech Stack

- React, Vite, Tailwind CSS, Express, Node.js

## Features

- Portfolio homepage
- Project showcase
- About and experience sections
- Contact form
- Backend email sending

## Getting Started

1. Open a terminal in the project folder.
2. Install dependencies:
   cd portfolio
   npm install
3. Start the app:
   npm run dev

## Run the Application

Open the app in your browser:

- http://localhost:5173

## Environment Variables

Create a .env file in the project root if needed with values like:

PORT=5000
MONGO_URI=mongodb://localhost:27017/your-db-name
JWT_SECRET=your-secret-key

## Notes

- Keep secrets and credentials in .env.
- Use separate branches for features and fixes.
- This folder is an independent Git repository.
